Made by AI, start to finish.

Every line of Cornea's shader code, this website and all of its text was written by AI. A person steered it, tested it in game and made the calls. This page says exactly what that means.

  • 100%: written entirely by AI. The shaders, the settings menus, the build tools, this site and its copy. Nothing was written by hand. You can read the whole conversation at the bottom of this page.
  • Models: Claude Opus 5.5 and Sonnet 5.5. Both ran through Claude Code. In the log below, Opus and Sonnet wrote the replies, and each one is labelled with the model that wrote it.
  • Human: one person steering. A person set the goals, sent screenshots, tested in game on a Ryzen 5 5500 and an RX 6500 XT, and decided what to keep. The AI can't see the game, so tuning followed that feedback.

Inspired by Photon. Not Photon.

Cornea chases the warm, soft look of Photon by SixthSurge. Here is how close the two really are, and where the line sits.

  • Photon was the target (goal). The goal was Photon's mood at a higher frame rate on a modest card. The comparison screenshots on the Features page are Photon, shown only so you can judge for yourself.
  • Its source was read as a reference (study). The AI studied Photon's shader files to learn techniques such as the sky look-up table, the light volume for coloured torches, soft shadows and temporal anti-aliasing. Photon's licence allows examining and learning from its source.
  • The code was written fresh (code). Cornea's files were written new, with their own structure and many different choices, and no Photon file was copied in. But reading Photon shaped the design, so the two share ideas and some layout. We can't promise no passage ever resembles it.
  • Only on this site, for now (sharing). Cornea is not on Modrinth, because it is AI-generated work. A CurseForge release may come later, but not yet, so this site is the only place to get it.
  • Checked, but young (status). Every program was compile-checked in several setting combinations and the author tested it in game. It is new, so expect rough edges and report what you find.
